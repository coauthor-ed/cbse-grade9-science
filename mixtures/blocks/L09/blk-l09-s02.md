# Why One Method Is Not Enough

<!-- STEP -->
## Run each method

It was reasonable to hope that one good method would do the whole job, but no single method can. Run each one on a full glass and see what it gives you.

- **Filter:** the pulp stays on the paper, and the other four parts come through together.
- **Distil:** pure water collects in the flask, and a thick syrup stays behind with the pulp in it.
- **Evaporate:** the same syrup stays behind, and this time the water is lost to the air.

**Each run gives you one part at most. The rest stay mixed.**

<!-- STEP -->
## Two methods, one after another

Now filter the lemonade and distil the clear liquid. You have two jars, pulp and water, and a sticky syrup of sugar, acid and colour.

You might think this is because a solution can never be separated. That is not the reason, because distillation took pure water out of salt water. The real reason is that **one method uses one difference.** None of the three boiled off with the water, so boiling point could not part them from one another.

Your textbook says that separation is not always simple. Parting those last three would take several more steps.

## The differences you know

Every separation uses a difference between the parts. Here are the ones you have used.

| Difference between the parts | Methods that use it |
|---|---|
| Size | Filtration |
| Density | Settling, separating funnel, centrifugation |
| Solubility | Dissolving one part, crystallization |
| Boiling point | Evaporation, distillation |
| How far it travels on paper | Paper chromatography |
| Magnetism | A magnet |
| Only one part sublimes | Sublimation |

Tap each difference and see what it can do for this glass.

## What each method cannot do

Each method also has limits, and knowing them saves you from a wrong choice. Try four tools on a glass of clear sugar water.

- **Filtration** cannot stop anything that is dissolved.
- **A separating funnel** works only on immiscible liquids.
- **A magnet** lifts only what is magnetic.
- **Evaporation** loses the liquid, so use **distillation** if you need it back.
- **Chromatography** gives only tiny amounts.

**Before you choose a method, ask two things: what is different about the parts, and which part do you need?**
