# The Main Methods, One Idea

You have now met the main separation methods. Each one uses a difference between the parts:

- **Filtration**: size.
- **Settling, the separating funnel and centrifugation**: density.
- **Coagulation**: size, because tiny particles clump into pieces big enough to sink or to stay on the paper.
- **Crystallization**: solubility.
- **Evaporation**: boiling point, because the water leaves as vapour and the solid stays.
- **Distillation**: boiling point.
- **Chromatography**: how far it travels on paper.
- **Sublimation**: one solid turns straight into vapour.
- **A magnet**: magnetism.

So if someone hands you a new mixture, how do you decide which method to use first? That is the next lesson.
