## What If Every Place Had the Same Species?

Imagine a world where every forest, wetland and hillside in India held exactly the same mix of species - nothing found only in one place, nothing endemic anywhere.

Working through what that would actually mean:

- "Biodiversity hotspot" would stop meaning anything. With no endemic species anywhere, no region would have the "many species found nowhere else" evidence a hotspot needs - every place would look equally ordinary.
- The Nilgiri tahr and Neelakurinji survive today specifically because they exist naturally only in one small area - so losing that one habitat would erase them completely. In this counterfactual, the same species would also live elsewhere, so one habitat's loss would no longer be a total loss.
- Conservation resources are always limited. If no place held anything unique, there would be no "this is genuinely irreplaceable" evidence to prioritise by - every location would need some other basis for the decision.

Real ecosystems are never actually like this - species really are unevenly distributed, and that unevenness is exactly why "lives only here" changes what losing a habitat actually costs.
