## What If Every Species Got a Made-Up, Standalone Name?

Imagine a system where every newly discovered species was given a completely made-up name with no genus, no family, and no connection at all to any other organism's name.

Working through what that would actually mean:

- A reader anywhere would have no way to tell the new species is related to anything else - a made-up standalone name carries no genus, so it connects to nothing else on record.
- The tiger's real address places it inside genus Panthera, family Felidae, order Carnivora and class Mammalia all at once - a standalone name would only identify the one organism, dropping every one of those broader connections.
- Binomial nomenclature works worldwide because the genus part of a name is real, shared information - tiger and lion both carry Panthera precisely because they're related. A standalone name would throw that shared information away entirely.

A nested address does more than identify one organism - it also places it among its relatives. A standalone name could do the first job, but never the second.
