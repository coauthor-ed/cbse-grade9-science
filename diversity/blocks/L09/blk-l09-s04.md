## Same Levels, Different Names

A pea plant has an address too, and it uses the same levels. All the names are different, because a pea and a tiger are in different kingdoms from the first level. Your book's list for the pea has no sub-phylum, so that row stays empty here.

## A Level and a Name

Family is a level. Felidae and Fabaceae are the names of the groups at that level. A level tells you how far down the address you are, and a name tells you which group you are in.
