## Double, then double again

The child would have 92 chromosomes and the grandchild 184, so the number would double in every generation. Yet each species keeps a fixed number. Human cells have 46, generation after generation, so a parent cannot pass on the full set.

<!-- STEP -->
## Twenty-three pairs

Humans have 23 pairs of chromosomes, which makes 46 in all. In each pair, one chromosome came from one parent and one from the other. Three pairs are drawn here.

<!-- STEP -->
## One from each pair

A special cell division called **meiosis** solves the problem. The chromosomes of each pair separate, so each **gamete** gets only one chromosome from each pair: 23 in all. Two gametes together give 23 + 23 = 46.
