# Worked: from fruit set to fruit in the basket

Take **200 fruit-bearing branches** in each orchard and do this in two stages for each: first the fruits that **set**, then the fruits that **drop**.

## Place A - natural pollinators

Fruit set is 26 per cent.

200 x 26 / 100 = **52 fruits set**.

Fruit drop is 35 per cent, and that is 35 per cent of the fruits set, not of the branches.

35 / 100 x 52 = about **18 fruits fall**.

52 - 18 = **34 fruits picked**.

## Place B - with a bee colony

Fruit set is 40 per cent.

200 x 40 / 100 = **80 fruits set**.

Fruit drop is 8 per cent of those 80.

8 / 100 x 80 = about **6 fruits fall**.

80 - 6 = **74 fruits picked**.

## The difference

74 - 34 = **40 more fruits** from the same 200 branches.

## The step that is easy to miss

Fruit set counts flowers that were reached. Fruit drop counts the pollination that **failed anyway** - the flower was visited, the pollen arrived, and the young fruit still let go.

So the colony did not only add fruits. It made the ones it added **stay**, and that is the bar that moved further: up 14 points for set, down 27 points for drop.

**The number of flowers is not the harvest. The number that survives is.**
