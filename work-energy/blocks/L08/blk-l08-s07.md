# A Beam Balance

<!-- STEP -->
## Coins in cups

Hang a scale from a string at its middle, with a cup on each side. One coin in each cup: the scale is level. Add a coin on the right: it tips. Move that cup closer to the middle, and it balances again.

<!-- STEP -->
## The rule

Try 1, 2, 4 and 8 coins. Each time, number of coins $\times$ distance is the same on both sides.

**effort $\times$ effort arm = load $\times$ load arm**
