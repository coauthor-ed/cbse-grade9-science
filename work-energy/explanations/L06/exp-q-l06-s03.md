# Power Is a Rate

<!-- STEP -->
## Work is an amount

Work is how much energy is transferred, in joules. Lifting a load to a height takes the same work, $mgh$, whoever or whatever lifts it.

## Power is how fast

Power is the work done each second, in watts: $P = \dfrac{W}{t}$.

A more powerful engine does the same work in less time. It does not do more work on the same job.
