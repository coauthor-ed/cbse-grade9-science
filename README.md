# CBSE Grade 9 Science

Courses for [CoAuthor](https://coauthor-ed.github.io/coauthor/), an offline-capable learning app.

## Courses
- Atomic Foundations: One Grain of Salt, Explained (`atomic-foundations-ox-alpha`)
- Cell: The Building Block of Life (`cells`)
- Patterns in Life, Diversity and Classification (`diversity`)
- Tissues in Action (`tissues`)
- Exploring Mixtures and Their Separation (`mixtures`)
- Reproduction: How Life Continues (`reproduction`)
- From a Shimmering Band to a Bat's Echo (`sound`)
- Work, Energy, and Simple Machines (`work-energy`)

## Add these courses
1. Open the app: https://coauthor-ed.github.io/coauthor/
2. Open the Parent area, then Settings, then Course sources.
3. Add this address: https://coauthor-ed.github.io/cbse-grade9-science/bundle-manifest.json

Once the Discover list is live, you can also find these courses in Discover.
